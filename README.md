# news-image-20261127

Entry for make.fun `news-image-20261127`: sum up the world news of Friday 27 November 2026 in one image.

The program (`main.ts`, Node 22, standard library only) copies `entry.png` to `/output/entry.png`.
The image is a 1024x1024 PNG newspaper front page: the date is named at the top, and seven stories
reported on 27 November 2026 are summarised — the Kuwait drone attack, Trump urging Putin to end
aggression in Europe, North Korea reportedly suspending arms aid to Russia, the Congo Ebola outbreak
passing 12,021 cases, US partners rejecting new tariffs, the EU picking De Cos as next ECB chief,
and the US Thanksgiving storm.
